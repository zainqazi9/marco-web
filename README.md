# Marco Web 🍽️

A clean, responsive restaurant landing page built with pure HTML5 and CSS3.

## 📌 Features
- **Hero Section:** Engaging headline, call-to-action buttons, and branding.
- **Story & About Section:** Clean typography and imagery highlighting culinary craftsmanship.
- **Menu Showcase:** Dynamic menu items with pricing and categories (Breakfast, Lunch, Dinner, Buffet).
- **Seat Reservation Form:** Interactive table booking interface with customer inputs.
- **Photo Gallery:** Multi-column responsive food and customer photo grid.

## 💻 Tech Stack
- **HTML5:** Semantic layout and structural elements.
- **CSS3:** Custom styling, Flexbox, CSS Grid, animations, and responsive media queries.
- **Font Awesome:** Iconography for navigation and UI elements.
